# 🍯 HoneyShield - AI-Powered Honeypot System

## What is this?
An AI-powered honeypot system that detects, tracks, 
and analyzes cyber attacks in real-time.

## Architecture
- 🕸️ Web Honeypot (Python Flask) - Cyber 2
- 🐚 SSH Honeypot (Cowrie) - Cyber 1  
- 🐳 Docker Infrastructure - DevOps
- 🤖 AI Analysis (Groq LLaMA 70B) - Cyber 3
- 🔔 Real-time Discord Alerts
- 📊 Live Dashboard

## Attack Types Detected
- SQL Injection
- XSS Attack
- Brute Force
- Bot Attack
- Credential Stuffing
- Command Injection
- Path Traversal
- Broken Authentication

## How to run
1. pip install -r requirements.txt
2. python app.py
3. python ai_analyzer_web.py
